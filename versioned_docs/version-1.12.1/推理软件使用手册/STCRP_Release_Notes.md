# STCRP Release Notes



## 概述

* STCRP是为自研AI推理芯片以及加速卡开发的配套软件，其中包括异构编程引擎、AI编译器以及满足模型监控调试、部署集成等用途的工具。STCRP Release Notes记录了各软件的版本、功能变更、问题修复等信息。STCRP V1.12.1中配套软件的版本信息如下：

  * HPE V1.9.7

    * stc-dkms V1.9.6

    * stc-kernel-common V1.9.6

    * hpert V1.4.3

    * hpert-dev V1.4.3

    * stcc V1.9.6

    * stc-smi V1.8.5

    * stc-prof V1.2.12

    * stc-gdb V1.8.3

    * stc-vprof V1.8.0

    * hpe-example V1.9.1

  * HPE Python V1.4.1

  * MLTC V1.6.1

  * SNQ V1.0.0

  * STC\_LLM V1.3.2

  * STC\_LLM\_DNN V1.3.1

  * STC\_IE V1.6.1

  * SNC V1.0.1
