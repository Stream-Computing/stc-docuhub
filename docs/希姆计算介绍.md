# 希姆计算

## 关于我们

广州希姆半导体科技有限公司秉持算力即服务的理念和精益求精的态度，依托自身硬科技创新到商业化落地的综合实力，持续面向AI设计先进的芯片、软件和系统，构建基于AI的全新服务，为各行各业的数智化转型提供算力、数据资产治理、大模型智能体等方面的广泛支持。

广州希姆半导体科技有限公司致力于为数智化转型提供RISC-V+AI创新解决方案，始终坚持软硬一体自主可控的发展方向，是RISC-V+AI计算公司中的领导者。基于自主研发的AI计算矩阵扩展指令集、NeuralScale NPC计算核心，推出了云端推理加速卡、大模型推理引擎、智算云平台、政企大模型、数据治理平台、智能体开发平台等产品，打通了从芯片指令集到AI应用的全链条，并面向典型场景持续丰富一体机产品线，为政企数智化转型提供一站式解决方案。

广州希姆半导体科技有限公司坚信RISC-V生态必将为AI时代提供澎湃算力，深度参与RISC-V生态的发展，先后被接纳为RISC-V国际基金会最高级别会员、RISC-V董事会成员单位、RISC-V TSC技术委员会成员单位、RISC-V软件应用与工具委员会主席单位、RISC-V AI/ML专委会主席单位和RISC-V Matrix TG核心成员单位；同时在国内积极推进RISC-V的广泛应用，先后当选中标协RISC-V工作委员会副会长单位、中国智能计算产业联盟副秘书长单位，以及全国信息技术标准化技术委员会-人工智能分技术委员会单位委员和多样性算力产业及标准推进委员会成员单位。
